🔌 Conexión al WMS

El backend expone POST /ingest como punto de entrada principal. Cualquier WMS externo puede enviar movimientos en formato JSON. Futuros adaptadores planificados para la Fase 4: SAP IDoc, importación CSV, MOCA protocol. 

curl -X POST http://localhost:8000/ingest \
  -H "Content-Type: application/json" \
  -d '{
    "movement_id": "MV-SAP-20260520-001",
    "timestamp": "2026-05-20T14:30:00",
    "movement_type": "PICK",
    "sku": "MX-0042",
    "location": "C-018",
    "user_id": "USR_001",
    "quantity": 10,
    "duration_sec": 60
  }'

Swagger UI: /api/docs  |  ReDoc: /api/redoc  |  OpenAPI JSON: /api/openapi.json

📋 Endpoints disponibles
Método Ruta Descripción Request / Response
GET / Dashboard web (esta página) HTML
GET /healthz Liveness probe para load balancers {"ok":true,"connections":1,"ollama_available":false}
POST /ingest Recibir movimiento de WMS externo {"accepted":true,"movement_id":"MV-..."}
WS /ws/alerts Stream de alertas y narrativas (WebSocket) JSON push: tipo alert o narrative
GET /api/status Estado del sistema en tiempo real {"connections":1,"anomaly_count":5,...}
GET /api/anomalies?limit=50 Últimas N anomalías (más recientes primero) [{"type":"alert","severity":"critical",...}]
POST /api/simulator/toggle Activar / desactivar simulador de movimientos {"running":true}
🔗 Contrato WebSocket — /ws/alerts

Al conectar, el servidor envía un mensaje hello. Luego llegan dos tipos de mensajes push:

Tipo: alert

{
  "type": "alert",          // siempre "alert"
  "movement_id": "MV-...",  // ID único del movimiento
  "severity": "critical",   // medium | high | critical
  "location": "C-018",      // pasillo-rack
  "movement_type": "PICK",  // tipo WMS
  "sku": "MX-0042",         // referencia producto
  "quantity": 10,           // unidades
  "duration_sec": 60,       // duración operación
  "timestamp": "2026-...",  // ISO 8601
  "rule_reasons": "..."     // reglas disparadas
}

Tipo: narrative

{
  "type": "narrative",       // siempre "narrative"
  "movement_id": "MV-...",  // correlaciona con alert
  "location": "C-018",      // misma que alert
  "narrative": "...",        // texto LLM principal
  "likely_cause": "...",     // causa probable (LLM)
  "recommended_action": "..." // acción recomendada
}
